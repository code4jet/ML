# Supervised Learning
- We have input data (X).
- We also have the correct output/target (y).
- The model learns the relationship between X and y from the training data.
- Then it uses that learned relationship to predict y for new/unseen X.
## Simple flow:<br>
Input (X) + Known Output (y)<br>
→ Train the model<br>
→ Learn relationship/pattern<br>
→ New Input (X)<br>
→ Predicted Output (ŷ)<br> 



# Regression: predicting numerical data from inputs

## Examples:
- House price prediction
- Salary/package prediction
- Stock price prediction

# Classification: predicting class (labels)

## Examples:
- Spam email detection
- Pass or fail prediction
- Disease diagnosis (positive/negative)
